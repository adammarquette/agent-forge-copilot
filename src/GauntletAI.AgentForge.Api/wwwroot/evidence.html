AgentForge — Click-to-Source Overlay DEMO

Upload a lab PDF, ask a question, then click a cited fact to highlight where it was read from (FR-CITE-2).

This is a self-contained demo of the citation → region rendering, not the clinician workflow. In production, documents are ingested pre-visit (uploaded in OpenEMR → cron → the sidecar extracts and persists facts), and the clinician turn reads those persisted facts — no in-turn upload. Here the browser renders the PDF you upload so the overlay works without fetching the source from OpenEMR. Wiring the overlay to the real flow (read persisted facts → fetch the OpenEMR DocumentReference Binary) is tracked in issue #109 (blocked on #81 / #40).
